# Brand guardrails

The rules every piece of content must pass. Load the files below, apply them, and report any conflict.

## Load first

1. `docs/brand/positioning.md`: the definition, the umbrella belief, the terms
2. `docs/brand/voice-and-tone.md`: how Linh sounds, banned words, spelling
3. `docs/brand/fact-sheet.md`: the only approved facts
4. `docs/brand/lp-vs-oa.md`: the channel split
5. `docs/funnel/cta-registry.md`: the one live CTA
6. `docs/OPEN-QUESTIONS.md`: check whether the task touches an open item

Load `docs/brand/audience.md` and `docs/brand/edge.md` when writing a script, hook or positioning line.

## The non-negotiables

1. **The definition is verbatim.** "An Intentional Founder is a business owner who decides what a good life looks like first, then builds a business that makes room for it." Say "defined by", not "coined by".
2. **Facts come only from the fact sheet.** Entrepreneur tenure is "nearly 15 years", always. If a number or fact is missing or marked 🟡, write `[CONFIRM WITH LINH: ...]` and do not invent. Never invent a client result, a quote or a statistic.
3. **Disclosure before diagnosis.** Linh names the pattern in herself first, then invites the viewer. Never open with "you're the bottleneck".
4. **Open on a person or a moment.** No welcome, no subscribe ask, no definition, no credential list in the first minute.
5. **One belief, one CTA.** One logical agreement and one emotional agreement toward "Don't just build a successful business. Build a successful life, intentionally." One primary ask from the registry.
6. **Keep the channel separate from Outsourcing Angel.** No standalone client case studies. No "here is OA's exact process". An OA mention is one soft sentence after the primary ask, never the only ask.
7. **Terms:** Intentional Founder (not Freedom Builder), accidental success, Task Delegator trap, free years, team member.
8. **Style:** first person, short sentences, contractions, Australian/UK spelling, no em dashes, no hype words (game-changer, unlock, supercharge, 10x, hack), no fear lists.
9. **Sensitive topics** (sobriety, faith, family detail) are Linh's call each time. Flag, do not assume.
10. **No team member or client is named without confirmed permission.**

## How to apply

**When writing:** keep the rules in view and produce the draft.

**When reviewing:** return a table with Rule, Pass/Fail, Where, Fix.

**When a rule conflicts with a request:** follow the request only if the user confirms, and note it in the output.

## Output footer for any draft

```
Brand check: definition ✓ | facts ✓ | disclosure-first ✓ | one belief ✓ | one CTA ✓ | LP vs OA ✓ | voice ✓
Open confirms: [list or none]
```

If anything fails, mark ✗ and say why.
