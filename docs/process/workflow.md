# Workflow: from topic to published

One video, one folder: `videos/YYYY-MM-DD-slug/`. The date is the Wednesday it goes live.

## Roles (adjust to your team)

| Role | Owns |
|---|---|
| **Linh** | Final yes on topic and script, filming, comment replies |
| **Strategist / producer** | Roadmap, briefs, gates, calendar |
| **Writer** | Script, description, Instagram pack |
| **Editor** | Cut, captions, end screen |
| **Designer** | Thumbnail, carousels |
| **Social manager** | Instagram scheduling, stories, comments |

## The timeline (working back from Wednesday)

| When | Step | Output | Skill |
|---|---|---|---|
| **T-21 days** | Confirm topic and slot | Roadmap row | `topic-validation` |
| **T-18** | Brief | `brief.md` | `video-package` |
| **T-16** | Titles, thumbnail concepts, hook options | In the brief | `hooks-and-titles`, `thumbnail-brief` |
| **T-14** | Draft script | `script.md` | `write-script` |
| **T-12** | QA and Linh's edits | Final script | `script-qa` |
| **T-10** | Film (and thumbnail expression) | Raw footage | n/a |
| **T-7** | Rough cut | Edit v1 | n/a |
| **T-5** | Thumbnail and description | `thumbnail-brief.md`, `description.md` | `thumbnail-brief`, `description-metadata` |
| **T-3** | Final cut, captions, end screen | Master | n/a |
| **T-2** | Instagram pack | `instagram.md` | `instagram-repurpose` |
| **T-1** | Schedule, UTMs, pinned comment | Scheduled | [publishing checklist](../youtube/publishing-checklist.md) |
| **T-0 Wed** | Publish, pin, reply, stories | Live | n/a |
| **T+3** | Check CTR and retention, swap thumbnail if needed | Notes | `analytics-review` |
| **T+7** | Record numbers, log stories | Review row | `analytics-review`, `story-bank` |

If a video needs Linh's travel or a number from her (W15, W22), move the whole timeline earlier and open the question in [OPEN-QUESTIONS](../OPEN-QUESTIONS.md).

```
├── script.md        # the script
├── thumbnail.md     # thumbnail brief and final notes

```

## Decision rules

- **Linh approves the script before filming.** No exceptions.
- **No script goes to filming with an open `[CONFIRM WITH LINH]`.**
- **A topic that fails the gate** is rewritten, not filmed as is.
- **A video that changes cluster or CTA** updates the roadmap and registry the same day.
- **When something is behind**, cut length, not the QA.

## Meetings

| Meeting | Cadence | Agenda |
|---|---|---|
| Content planning | Weekly, 30 min | Next two slots, open questions, blockers |
| Review | Weekly, 15 min | Last video's numbers, one change to make |
| Monthly review | Monthly, 45 min | [Analytics review](analytics-review.md), roadmap adjustments, Instagram review |

## Handoffs

Each person leaves the folder in a state anyone could pick up. Use the status line at the top of `README.md`:

`Status: Brief → Script draft → Script approved → Filmed → Edited → Packaged → Scheduled → Live → Reviewed`
