# Playlists

Playlists are how YouTube keeps a viewer on the channel for a second video. Outside viewers leave early, so a playlist and an end screen pointing to the next video in the same cluster is the cheapest retention fix after the intro.

## Playlist fixes

1. **A "Start Here" with six videos is not a start here.** Cut it to three, in the order you want a stranger to watch.
2. **No playlist holds a single video.** Merge Hiring into the delegation list now so each can carry a session.
3. **Rename "Founder Freedom: Start Here" on the same day as the channel rename** (planned Wed 2 Dec 2026). See the [rebrand checklist](rebrand-checklist.md).

## Order for a stranger (Start Here)

1. **4 Hidden Costs of Doing Everything Yourself**: names the cost, opens on Linh's panic attacks. Best click, strong watch.
2. **5 Delegation Steps**: the proof the viewer can get out. Best watch time on the channel.
3. **Are You an Accidental Founder?** (live 2 Dec): the identity video. This is the one that names the brand.

## Rules for every video

- **End screen**: one named next video from the same cluster.
- **Description**: one line pointing to that same video.
- **Spoken close**: name the next video. Do not say "thanks for watching, subscribe".
- Each video belongs to exactly one primary playlist.
