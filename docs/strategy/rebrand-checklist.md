# Rebrand checklist: Founder Freedom → The Intentional Founder

**Do all of it on one day.** Planned: **Wed 2 Dec 2026**, the day the "Are You an Accidental Founder?" video goes live. Confirm with Linh first ([open question 3](../OPEN-QUESTIONS.md)).

The channel name and handle still say Founder Freedom, descriptions call viewers "Freedom Builders", and tags lead with "founder freedom". Changing one without the rest leaves a split identity.

## Before the day (prep, no public change)

- [ ] Linh approves the new channel name and handle. Check the handle is free.
- [ ] New banner designed (see [thumbnails.md](../youtube/thumbnails.md) for colours and type).
- [ ] New channel description written, with the definition and the one CTA.
- [ ] Channel trailer decision: keep, replace or retire.
- [ ] New playlist names and order ready ([playlists](playlists-and-clusters.md)).
- [ ] Description template updated ([template](../../templates/description-template.md)).
- [ ] W14 video filmed, edited, thumbnail ready.
- [ ] Instagram bio and highlight names drafted to match.
- [ ] Website: `/intentional-founder` live and linked from nav, homepage hero label, footer and book page.
- [ ] Email to the list drafted announcing the rename.

## On the day

- [ ] Change channel name and handle.
- [ ] Upload new banner and profile image if changed.
- [ ] Replace the About text and links.
- [ ] Rename "Founder Freedom: Start Here" to "Start Here: The Intentional Founder", cut to 3 videos.
- [ ] Rename and merge the other playlists.
- [ ] Publish the W14 video.
- [ ] Update default description and tags. Remove "Freedom Builder".
- [ ] Update Instagram bio and link.
- [ ] Send the list email.
- [ ] Pin a comment on the W14 video that explains the new name in one line.

## After (first two weeks)

- [ ] Check Studio for any drop in returning viewers.
- [ ] Update older video descriptions that still say "Freedom Builders" (start with the three Start Here videos).
- [ ] Update the website footer and bio links to match.
- [ ] Record the date in [roadmap](roadmap.md) and the [CTA registry](../funnel/cta-registry.md).
