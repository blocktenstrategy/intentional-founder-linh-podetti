# Description and metadata

Template to copy: [templates/description-template.md](../../templates/description-template.md).

## Description structure

| Block | Content | Notes |
|---|---|---|
| **Line 1 to 2 (above the fold)** | One-sentence promise + the **one CTA with link** | Only about 100 characters show before "more". Put the CTA first. |
| **Next-video line** | "Watch next: [title] [link]" | The next video in the same playlist |
| **Summary** | 2 to 3 sentences using the problem keywords | For search, written like a person |
| **Chapters** | `0:00` lines. Each chapter is a reason to keep watching. | Starts at `0:00`. Minimum three. |
| **About Linh** | One line: definition and who she is | Same wording everywhere ([fact sheet](../brand/fact-sheet.md)) |
| **Links** | The CTA again and the book. Not a link list. | Max 3 links |
| **P.S. (when live)** | Intentional Year line, Nov and Dec only | A P.S., not a second CTA |
| **Hashtags** | 3 max, at the end | `#IntentionalFounder` plus two topic tags |

## Chapters: write for the viewer, not the editor

| Instead of | Write |
|---|---|
| Intro | Why I asked my assistant about my dentist |
| Lesson 1 | Start with one boring, repeated job |
| Lesson 2 | What the AI got wrong |
| Recap | The five lessons in 30 seconds |

## Pinned comment

One question tied to the exercise, plus the CTA. Example:

> What's the ONE repeated job you're handing to AI first? Tell me below. If you'd like to see how much of your time is actually yours, the Free Years Calculator is here: [link]

## Tags

- Lead with the **problem keywords** (delegate, bottleneck, remote team, virtual assistant, automate).
- Add "intentional founder" as one tag, not the first.
- Remove "Freedom Builder" and lead tags that say "founder freedom" after the rename.

## Search and answer engines

Write the summary so it answers the question in the title in one sentence, plain text. YouTube and AI answer engines both quote the first clear answer. Use the definition verbatim when the video is about the term.
