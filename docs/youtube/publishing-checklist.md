# Publishing checklist

Copy into the video folder's `README.md` and tick as you go.

## 1. Before filming

- [ ] Topic is on the [roadmap](../strategy/roadmap.md) with a cluster, funnel step and belief line
- [ ] Brief written ([template](../../templates/video-brief.md))
- [ ] Title: three options, S/A/P result recorded
- [ ] Thumbnail: concept chosen, expression and prop noted for the shoot
- [ ] Script drafted in the [template](../../templates/script-template.md)
- [ ] `script-qa` passed (no open `[CONFIRM WITH LINH]`)
- [ ] Facts match the [fact sheet](../brand/fact-sheet.md)
- [ ] Story and examples checked against the [story bank](../process/story-bank.md)
- [ ] Any named team member or client has agreed
- [ ] CTA taken from the [registry](../funnel/cta-registry.md)

## 2. Filming

- [ ] Hook shot first, three takes
- [ ] The thumbnail expression shot
- [ ] B-roll and on-screen text cues listed
- [ ] Linh's availability checked (she is away 16 to 19 Nov)

## 3. Edit

- [ ] First 60 seconds tight, no pitch, no welcome
- [ ] Length 8 to 12 minutes
- [ ] On-screen text lands the one line per lesson
- [ ] Captions checked for names and spellings (Australian English)
- [ ] End screen: one named next video

## 4. Package

- [ ] Title final
- [ ] Thumbnail final, phone-size test passed
- [ ] Description, chapters, tags ([guide](description-and-metadata.md))
- [ ] Pinned comment ready
- [ ] Playlist and end screen set
- [ ] UTM links created

## 5. Publish (Wednesday)

- [ ] Scheduled for the slot
- [ ] Pinned comment posted within 5 minutes
- [ ] Linh replies to the first comments the same day
- [ ] Instagram pack scheduled ([repurposing system](../instagram/repurposing-system.md))
- [ ] Newsletter or email mention if the slot calls for it

## 6. After

- [ ] 48 to 72 hours: check CTR and early retention. If CTR is under 2%, swap the thumbnail.
- [ ] 7 days: record views, CTR, average view duration, subscribers in the [analytics review](../process/analytics-review.md)
- [ ] Stories and examples logged in the story bank
- [ ] Update **Status** in the roadmap
- [ ] Move any follow-up topic ideas to the roadmap
