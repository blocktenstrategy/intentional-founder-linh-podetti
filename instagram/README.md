# Instagram

The strategy is in [docs/instagram/](../docs/instagram/). This folder holds the working calendar.

- `calendar/YYYY-MM.md`: one file per month with the plan, the posts and the review notes

Start a month by asking Claude: "Use `instagram-growth-plan` to plan [month] from the roadmap."

## Month file template

```md
# [Month YYYY]

Focus lever (one): [from the growth playbook]
YouTube uploads this month: [titles and dates]

| Date | Post | Pillar | Source video | Ask | Status |
|---|---|---|---|---|---|

## Review (end of month)
Best three posts, worst three, what changed, one change for next month.
```
