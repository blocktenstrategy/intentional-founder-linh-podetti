# Thumbnails

The system lives in [docs/youtube/thumbnails.md](../docs/youtube/thumbnails.md). This folder holds:

- [`reference/analysis.md`](reference/analysis.md): review of every current thumbnail with CTR data and next ideas
- Design notes and exports **only when the team wants them in git**. Large files and source files are ignored (see `.gitignore`).

Brief a new thumbnail with [templates/thumbnail-brief.md](../templates/thumbnail-brief.md) or the `thumbnail-brief` skill.
