# Videos

One folder per video: `YYYY-MM-DD-short-slug`, the date being the Wednesday it goes live.

```
videos/2026-12-02-accidental-founder/
├── README.md        # status line + publishing checklist
├── brief.md         # from templates/video-brief.md
├── script.md        # from templates/script-template.md
├── thumbnail.md     # from templates/thumbnail-brief.md
├── description.md   # from templates/description-template.md
├── instagram.md     # carousel and reel copy
└── results.md       # from templates/weekly-retro.md
```

Start one by asking Claude: "Use `video-package` to start the folder for [roadmap slot]".

## `README.md` for a video

```md
# [Title]
Status: Brief | Script draft | Script approved | Filmed | Edited | Packaged | Scheduled | Live | Reviewed
Slot: [W#, date] · Cluster: [..] · CTA: [..]
Open confirms: [..]

(Paste docs/youtube/publishing-checklist.md below and tick as you go.)
```
